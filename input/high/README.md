# Тестовые входные данные для 2D fan-beam CT (повышенное разрешение)

Синтетические **карты коэффициента ослабления** `mu(x,y)` для проверки прямой задачи и реконструкции. Это не фотографии багажа и не реальные измерения детекторов.

## Структура

- `input/*.png` и `input/*.pgm` — **256×256** пикселей, 9 примеров, имена согласованы со старым набором (первые шесть).
- `input/highres_512/*.png` и `input/highres_512/*.pgm` — **512×512**, те же 9 геометрий с более мелкими деталями.
- `input/manifest.csv` — перечень фантомов.

PNG — **8-битный grayscale**, PGM — двоичный `P5` (8 бит). Численные данные в парных файлах полностью совпадают. Изображения сформированы из геометрических примитивов с усреднением по подпикселям на границе. Небольшие промежуточные значения на краях соответствуют частично заполненным пикселям; это не шум.

| Имя | Назначение |
|---|---|
| `00_empty` | Пустая область, идеальные проекции равны 0 |
| `01_uniform_disk` | Однородный круг для отладки трассировки |
| `02_two_materials` | Проверка контраста между материалами |
| `03_rectangles_rotated` | Наклонные границы, тест геометрии |
| `04_suitcase` | Условное сечение чемодана с предметами |
| `05_fine_details` | Тонкие линии, кольца, небольшие детали |
| `06_nested_materials` | Полости и вложенные слои |
| `07_packed_suitcase` | Более сложный и плотный багаж |
| `08_resolution_target` | Тест разрешения: линии, полосы, круги |

## Интерпретация пикселей

Значение яркости `pixel` от 0 до 255 нужно перевести в коэффициент ослабления:

```cpp
double mu = (static_cast<double>(pixel) / 255.0) * mu_max;
```

Здесь `mu_max`, например `1.0`, задаётся в **обратных единицах длины той же геометрии**, что и матрица `A`. Значения условные, не являются физическими коэффициентами реальных материалов. Не используйте sRGB-гамма-коррекцию, автоконтраст и фильтрацию при загрузке.

Координаты пикселей: `row=0` — верхняя строка изображения. Для `Eigen::VectorXd` при построчном обходе: `index = row*n + col`. Координату `y` в математической сетке нужно сопоставлять порядку строк последовательно (верхняя строка соответствует наибольшему `y`).

## Важное замечание о размерах

В 256×256 изображении **65 536** неизвестных, в 512×512 — **262 144**. Если оставить 120 ракурсов и 96 детекторов, получается только 11 520 измерений — система становится **недоопределённой**. Это нормально для экспериментов с разреженными проекциями и регуляризацией, но для честного сравнения со старым набором нужно либо увеличить число ракурсов/детекторов, либо явно учитывать недостаточность данных.

Для первых отладочных экспериментов используйте `01_uniform_disk` на 256×256; более сложные варианты и 512×512 пригодятся на последующих этапах.
