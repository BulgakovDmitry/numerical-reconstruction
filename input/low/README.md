# Тестовые входные данные для 2D fan-beam CT

Все файлы — **синтетические карты коэффициентов ослабления**, а не рентгеновские снимки и не реальные изображения багажа.

- Размер: **64 × 64 пикселя**.
- Форматы: **PNG (8-битный grayscale)** и **PGM (P5)**; обе версии каждого изображения содержат одинаковые значения.
- Один пиксель = один коэффициент ослабления в модели. Значения намеренно дискретные, без сглаживания границ.
- Пиксели индексируются как `image[row][col]`, `row = 0` — верхняя строка; при разворачивании в `Eigen::VectorXd` используйте `index = row * 64 + col`.

## Примеры

| Файл | Для чего нужен |
| --- | --- |
| `00_empty` | Нулевой объект: при идеальной прямой модели все интегралы должны быть нулевыми |
| `01_uniform_disk` | Однородный круг: тест проекций и восстановления простой геометрии |
| `02_two_materials` | Два круга с разным ослаблением: проверка контраста |
| `03_rectangles_rotated` | Прямоугольник и наклонная полоса: проверка пересечений лучей с границами |
| `04_suitcase` | Условное сечение багажа с разными предметами: демонстрационный тест |
| `05_fine_details` | Тонкие линии, кольцо и маленькие детали: чувствительность к разрешению/регуляризации |

## Перевод интенсивности пикселя в коэффициент μ

Нужно выбрать масштаб, например `mu_max = 1.0` **в обратных единицах длины, используемых геометрией**. Затем:

```cpp
double mu = static_cast<double>(pixel) / 255.0 * mu_max;
```

Чёрный пиксель (`0`) означает `mu = 0`, белый (`255`) — `mu = mu_max`. Значения 42, 72, 115, 150, 184, 220 и т. п. — **условные значения**, не табличные свойства реальных материалов.

Если размер области реконструкции равен `2.0 × 2.0` в условных единицах, шаг сетки `h = 2.0 / 64`. Физический масштаб выбирайте согласованно со значениями `mu_max`.

## Использование

1. Загрузите файл `.png` или `.pgm` как одноканальное изображение, без автонормализации, коррекции яркости и изменения размера.
2. Преобразуйте интенсивности `uint8` в `double` по формуле выше и разверните матрицу в `mu_true`.
3. Для симуляции выполните `b = A * mu_true` (при необходимости добавьте шум только **после** этого шага).
4. Восстановление должно получать **только** `A` и `b`; `mu_true` используется отдельно для вычисления RMSE.

Не используйте форматы с потерями вроде JPEG: они добавляют нежелательные артефакты к тестовой карте.
